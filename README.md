# 📚 Library Management System API

A RESTful API for managing a list of books using **Spring Boot**, **MySQL**, **Hibernate**, and **Spring Data JPA**.

---

## 🚀 Technologies Used

- Java 17+
- Spring Boot
- Spring Web
- Spring Data JPA
- Hibernate
- MySQL
- Maven
